Jarvis setup

1. Microphone

Chrome can't ask for the mic inside the popup, so allow it here once.

2. Groq key (optional)

Used only when a command doesn't match the built-in phrasings. Stored in this browser only, unencrypted.

3. Voice

Voices marked “Natural” or “Google” sound the most human.

4. Shortcut

Alt+J opens Jarvis. Change it at chrome://extensions/shortcuts.
